# Perencanaan Penulisan SRS - 2.4 Constraints

*Referensi Panduan IEEE 830-1998:*
> Bagian kendala (Constraints) memberikan penjelasan umum mengenai batasan-batasan desain yang akan memengaruhi cara pengembang dalam merealisasikan perangkat lunak atau keras, misalnya kendala perangkat keras, regulasi, dll.

---

### **Rencana Isi (Plan) untuk ATLAS - 2.4 Constraints:**
1. **Kendala Perangkat Keras:** Mikrokontroler ESP32 memiliki keterbatasan memori dan *processing power* sehingga algoritma jarak harus efisien.
2. **Kendala Komunikasi LoRa:** Lebar pita (bandwidth) LoRa terbatas; ukuran data telemetri yang dikirim harus sangat kecil.
3. **Kendala Konektivitas Internet:** Ketergantungan *gateway* pada sinyal Wi-Fi/GSM untuk pengiriman data ke Website. Jika internet mati, Website tidak *update*, walau sistem lokal tetap jalan.
4. **Kendala Antarmuka:** Tidak diperbolehkannya penggunaan layar sentuh atau instrumen rumit di kabin masinis sesuai regulasi keselamatan.
