# Perencanaan Penulisan SRS - 1.4 References

Dokumen ini berisi rencana penulisan terfokus untuk bagian **1.4 References** dari dokumen *Software Requirements Specification* (SRS) untuk sistem **ATLAS**.

## Fokus Isi Bagian 1.4 References

Pada bagian ini, kita akan mencantumkan seluruh dokumen, standar, dan sumber referensi yang dirujuk di dalam dokumen SRS ini dengan format penomoran referensi gaya IEEE (contoh: [1], [2]). Poin-poin yang akan dimasukkan ke dalam draf akhir adalah:

1. **Standar IEEE (Wajib):**
   - **[1]** IEEE Std 830-1998, *IEEE Recommended Practice for Software Requirements Specifications*. Tersedia: https://standards.ieee.org/ieee/830/1183/

2. **Dokumen Proyek Internal:**
   - **[2]** *Concept of Operations (ConOps)*, Versi 1.0. (Dokumen Internal).
   - **[3]** *Hardware Design Specification*, Versi 1.0. (Dokumen Internal).

3. **Datasheet & Dokumentasi Teknis Komponen:**
   - **[4]** Semtech, *SX1276/77/78/79 Transceiver Datasheet*. Tersedia: https://semtech.my.salesforce.com/sfc/p/#E0000000JelG/a/2R0000001Rbr/6EfVZUorrpoFJA178KOnQ1gYyRzF15i27T3iM1v929g
   - **[5]** u-blox AG, *ZED-F9P Integration Manual*. Tersedia: https://www.u-blox.com/en/docs/UBX-18010802
   - **[6]** Espressif Systems, *ESP32 Technical Reference Manual*. Tersedia: https://www.espressif.com/sites/default/files/documentation/esp32_technical_reference_manual_en.pdf

4. **Regulasi & Standar Keselamatan Perkeretaapian:**

   - **[8]** IEC, *IEC 62280: Security for Railway Communication Systems*. Tersedia: https://webstore.iec.ch/publication/60555
