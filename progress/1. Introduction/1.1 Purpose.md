# 1. Introduction

## 1.1 Purpose

Software Requirements Specification (SRS) ini disusun guna menyediakan dokumentasi terstruktur mengenai spesifikasi dan kebutuhan sistem ATLAS: Decentralized P2P Train Telemetry & Braking Alert System. Tujuan penyusunan dokumen SRS adalah untuk menjelaskan berbagai kebutuhan dalam pengembangan purwarupa sistem aplikasi berdasarkan hasil analisis kebutuhan, mencakup gambaran umum serta penjelasan fungsi sistem secara detail dan menyeluruh. Sistem ATLAS merupakan sistem peringatan dini tabrakan kereta api yang mengintegrasikan arsitektur *on-board* terdesentralisasi (memanfaatkan mikrokontroler ESP32, komunikasi LoRa P2P, dan GPS RTK) dengan platform pemantauan jarak jauh berbasis antarmuka Website analitik visual. Dokumen ini mendefinisikan persyaratan pengoperasian sistem dalam mendeteksi posisi kereta, menyalakan peringatan cahaya LED dan membunyikan suara Buzzer secara lokal, serta mengirimkan data telemetri ke server untuk dianalisis melalui website, sehingga pengawasan dapat dilakukan secara komprehensif. Dokumen ini akan digunakan sebagai dokumentasi dan bahan acuan utama dalam perancangan arsitektur IoT, pengembangan *software* web, dan integrasi perangkat keras.

Dokumen SRS ini disusun untuk digunakan oleh beberapa lapisan pengguna utama yang terlibat dalam pengembangan sistem ATLAS. Bagi tim pengembang, dokumen ini berfungsi sebagai panduan teknis implementasi perangkat keras ESP32, interkoneksi LoRa, modul peringatan visual/audio (LED dan Buzzer), aktuator pengereman, hingga arsitektur integrasi sistem pengiriman data menuju platform Website analitik visual. Selain itu, dokumen ini digunakan oleh tim penguji sebagai acuan dalam memvalidasi keakuratan deteksi sensor *on-board* serta sinkronisasi visualisasi data telemetri yang ditampilkan pada Website dasbor pemantauan. Bagi pengguna akhir (masinis dan tim pengawas lapangan), dokumen ini memberikan gambaran yang jelas mengenai operasional sistem dalam menunjang respons tanggap darurat guna mencegah kecelakaan.

Mengingat sistem ATLAS saat ini dikembangkan dalam skala purwarupa Minimum Viable Product (MVP), dokumen ini difokuskan pada pemenuhan fungsional utama dari modul *on-board* ESP32 beserta dasbor Website analitik. Dengan demikian, cakupan dokumen ini tidak membahas perihal regulasi sertifikasi perangkat keras industri perkeretaapian berskala nasional maupun integrasi penuh dengan sistem persinyalan konvensional PT KAI.
