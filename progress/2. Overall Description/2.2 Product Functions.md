# 2. Overall Description

## 2.2 Product Functions

Sistem ATLAS ini dirancang dan dikembangkan untuk dapat mengeksekusi beberapa fungsi pokok secara paralel dan berkesinambungan sebagai berikut:

a. **Pemosisian Presisi Geografis:** Modul pengolah utama (ESP32) mengekstrak *string* data spasial, seperti garis lintang, garis bujur, ketinggian, dan kecepatan laju dinamis kereta secara *real-time* melalui komunikasi serial satelit dari sensor pembaca GPS RTK.

b. **Transmisi Data Terdesentralisasi:** Ekosistem komunikasi *on-board* memancarkan *broadcasting* paket data telemetri lokomotif sekaligus secara independen "mendengarkan" siaran telemetri dari armada kereta yang mendekat dalam radius pemantauannya melalui gelombang radio LoRa P2P.

c. **Kalkulasi Ancaman Tabrakan:** Mikrokontroler menghitung estimasi jarak pemisah relatif antara armada berdekatan berbekal titik potong koordinat yang dipertukarkan untuk mengantisipasi probabilitas terjadinya *head-on collision* atau ancaman *blind-spot* lainnya secara otonom di ranah lokal tanpa beban komputasi di pusat *server*.

d. **Peringatan Dini (Pancaran Cahaya dan Suara):** Perangkat keras akan secara instan mengaktifkan aktuasi pada modul indikator fisik dengan memancarkan kerlipan cahaya LED warna tertentu serta resonansi suara bernada tinggi via Buzzer saat batas jarak aman peringatan pertama terdeteksi, mengingatkan masinis secara awas di kabin lokomotif.

e. **Intervensi Pengereman Otomatis:** Sistem memberikan tenggat waktu (*grace period*) bagi respons pengereman sadar dari masinis setelah alarm diaktifkan. Apabila tidak ada manuver perlambatan yang terdeteksi, modul *relay hardware* bertindak seketika sebagai pemutus laju untuk intervensi memberhentikan kendaraan berat secara otonom.

f. **Pemantauan Analitik Visual Berbasis Web:** ATLAS melakukan *logging* jejak telemetri armada dan notifikasi alarm darurat yang selanjutnya ditransmisikan melalui antarmuka *gateway* menuju *server cloud*. Fitur fungsional ini memungkinkan data tersebut disaring, dirangkum, dan dipetakan di atas aplikasi layar antarmuka Website terpadu yang dapat diakses oleh pimpinan stasiun (*dispatcher*) untuk evaluasi *monitoring* operasional jarak jauh.
