# 2. Overall Description

## 2.5 Assumptions and Dependencies

Spesifikasi perancangan sistem ATLAS dilandaskan pada sejumlah asumsi prasyarat serta interdependensi spesifik yang krusial. Apabila salah satu di antara elemen fundamental ini tidak terwujud sesuai skenario, fungsionalitas pengamanan sistem niscaya akan mengalami disrupsi. 

**Asumsi Inti (Assumptions):**
1. **Penerimaan Sinyal Satelit Terbuka:** Pemosisian spasial diasumsikan berjalan mulus karena kereta api pada umumnya melintasi jalur geografis *outdoor* beratap terbuka, sehingga sensor GPS RTK selalu diestimasikan sukses mengunci minimal empat konstelasi satelit secara statis untuk memperoleh validasi koordinat absolut.
2. **Ketersediaan Pasokan Daya Kontinu:** Modul elektronika ESP32, sensor, dan aktuator *relay* diasumsikan tidak akan kehilangan tegangan operasi (*voltage*), merujuk pada stabilnya suplai *power* aki atau generator induksi lokomotif selama unit armada tersebut berdinas di atas rel.
3. **Pemeliharaan Aktuator Mekanis:** Piranti rem angin hidrolik atau traksi elektromekanik milik pabrikan lokomotif senantiasa diasumsikan dalam kondisi prima. Sistem ATLAS sekadar men- *trigger* relai aktuator pengereman otomatis tanpa memiliki wewenang untuk mendiagnosis keausan bantalan rem lokomotif.

**Ketergantungan Eksternal (Dependencies):**
1. **Interdependensi Stasiun Koreksi Presisi (Base Station RTK):** Meskipun berlabel sistem otonom terdesentralisasi, tingkat toleransi akurasi tingkat sentimeter ATLAS sangat bergantung kuat pada distribusi kontinu paket data koreksi RTCM (*Radio Technical Commission for Maritime Services*) dari *Base Station* GPS terestrial. Putusnya koneksi perujukan koreksi ini akan menjatuhkan performa ATLAS kembali ke mode pembacaan GPS standar (akurasi bias hitungan meter).
2. **Ketergantungan Infrastruktur Penunjang Website:** Keandalan pengarsipan *database* histori telemetri bergantung utuh pada ketersediaan ruang server komputasi awan (*Cloud Hosting*) 24/7 pihak ketiga, berikut dukungan perpanjangan _bandwidth_ seluler (kartu SIM IoT GSM / *Wi-Fi Hotspot*) pada ujung modul *gateway* ATLAS untuk me- *relay* *log* keselamatan harian kepada para *dispatcher*.
