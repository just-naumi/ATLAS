# 2. Overall Description

## 2.1 Product Perspective

Sistem ATLAS merupakan sebuah ekosistem peringatan dini keselamatan kereta api yang mengkombinasikan keandalan perangkat keras tertanam (*embedded system*) berbasis mikrokontroler ESP32 dengan platform pemantauan digital berupa Website Analitik Visual. ATLAS diposisikan sebagai *Secondary Safety System* (sistem pengaman lapis kedua) khusus untuk mendeteksi jarak aman dan mencegah potensi tabrakan, tanpa bermaksud mengambil alih sistem *interlocking* atau kendali persinyalan bawaan dari infrastruktur perkeretaapian yang sudah ada. 

Sebagai sebuah ekosistem *hybrid*, ATLAS berinteraksi melalui beberapa lapisan antarmuka operasional. Pada sisi *on-board* (di lokomotif), sistem mengandalkan arsitektur komunikasi terdesentralisasi *Peer-to-Peer* (P2P) berbasis pancaran sinyal gelombang radio LoRa untuk melangsungkan pertukaran data telemetri antar-kereta secara paralel dan independen. Hal ini memastikan bahwa deteksi ancaman keselamatan dapat beroperasi mutlak tanpa memerlukan sinyal seluler (*internet*) komersial. Pada sisi perangkat keras antarmuka masinis, ESP32 berinteraksi dengan modul GPS RTK sebagai sumber input koordinat presisi, perangkat *output* aktuator relay mekanik untuk *automatic braking*, serta modul *output* indikator berupa lampu LED peringatan dan Buzzer akustik.

Selain kapabilitas isolasinya di lapangan, ATLAS memiliki lapisan antarmuka perangkat lunak melalui Website Analitik Visual jarak jauh. Sebuah *gateway* komunikasi dalam ekosistem *on-board* akan merekam dan meneruskan paket-paket parameter keselamatan dan jejak peringatan ke *cloud server* via protokol TCP/IP (memanfaatkan fitur Wi-Fi ESP32 atau modem GSM tambahan jika tersedia). Antarmuka pengguna (*User Interfaces*) pada ATLAS pun terbagi dua secara tegas: masinis berinteraksi murni melalui respons fisik terhadap nyala LED dan nyaring bunyi Buzzer di kabin agar konsentrasi mengemudi tidak terpecah, sedangkan *dispatcher* atau pengawas di stasiun disuguhkan antarmuka *dashboard* grafis berbasis Web yang sarat akan visualisasi analitik statistik pergerakan kereta.
