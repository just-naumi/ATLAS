# 2. Overall Description

## 2.3 User Characteristics

Dalam rantai operasionalnya, sistem ATLAS akan digunakan dan dikelola oleh tiga kelompok pengguna utama yang memiliki karakteristik latar belakang, tingkat keahlian, dan lingkup wewenang tugas yang berbeda. Karakteristik dari pengguna-pengguna sistem ini dideskripsikan sebagai berikut:

a. **Masinis (Pengguna Akhir Lapis Utama):** Merupakan pihak operator yang berinteraksi langsung secara pasif dengan perangkat di dalam kabin ruang kemudi lokomotif. Masinis diasumsikan murni memiliki keahlian operasional laju moda transportasi berat, namun tidak diwajibkan untuk menguasai landasan akademis jaringan IoT, arsitektur modulasi LoRa, maupun perakitan *hardware*. Fokus absolut masinis bertumpu pada observasi jalur kereta api. Oleh karena itu, *interface on-board* ATLAS dirancang tanpa tampilan GUI *touch-screen* rumit, dan ditujukan sekadar sebagai instrumen reaktif yang membunyikan modul Buzzer serta menyalakan kedipan cahaya LED untuk memancing tanggapan psikomotorik masinis di detik-detik kritis.

b. **Teknisi Sistem (Administrator Instalasi Eksekutor):** Merupakan personel pakar yang memegang mandat terhadap eksekusi fisik perakitan instalasi, perumusan parameter fungsional ESP32, kalibrasi kepekaan GPS RTK, serta pemeliharaan sambungan sirkuit pada aktuator *relay* pengereman. Pengguna pada kategori eksklusif ini mensyaratkan portofolio keahlian teknis strata lanjut pada ruang lingkup mikrokontroler terprogram dan instalasi elektronika arus lemah. Komponen *on-board* ATLAS tidak memanjakan personel teknisi dengan *dashboard* visual internal, melainkan mewajibkan mereka menavigasikan pemeliharaan sistem melalui *line-code* pada akses *serial monitor* secara komprehensif.

c. **Dispatcher / Pengawas Stasiun (Pengguna Akhir Lapis Manajerial):** Merupakan perwira lalu lintas kereta api yang duduk di ruangan pusat kendali (OCC) stasiun atau gedung manajemen fungsional. Profil *user* jenis ini sangat mahir mengoperasikan perangkat lunak analitik manajerial dan membaca peta jaringan komputer komersial. Kebutuhan *dispatcher* diakomodasi murni pada akses jaringan antarmuka **Website Analitik Visual**. Sistem bagi pengawas dituntut untuk berpenampilan modern (*user-friendly*), stabil menangani data *streaming* log telemetri masuk, serta mumpuni menampilkan agregat laporan rekam jejak alarm peringatan ATLAS pada armada tertentu tanpa menyulitkan daya penalaran petugas pusat kendali.
